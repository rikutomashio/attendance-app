# 勤怠管理アプリ

## アプリケーション概要

Laravelを用いて作成した勤怠管理アプリです。  
一般ユーザーと管理者の2権限構成を採用し、勤怠登録から修正申請承認までを一貫して行うことができます。

### 一般ユーザー機能

- 会員登録
- ログイン / ログアウト
- メール認証
- 出勤 / 退勤登録
- 休憩開始 / 終了
- 勤怠一覧表示
- 勤怠詳細確認
- 勤怠修正申請
- 修正申請一覧

### 管理者機能

- 管理者ログイン
- 日次勤怠一覧
- スタッフ一覧
- スタッフ別勤怠一覧
- 勤怠詳細確認 / 修正
- 修正申請一覧
- 修正申請承認
